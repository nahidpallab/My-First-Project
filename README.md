# Browser Jigsaw Puzzle Game

A lightweight browser game that turns any uploaded image into a jigsaw puzzle.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.

## How to play

1. Click **Choose Image** and select your picture.
2. Pick a difficulty (3x3, 4x4, or 5x5).
3. Click **Start Puzzle**.
4. Drag a tile onto another tile to swap positions until the image is fully restored.
